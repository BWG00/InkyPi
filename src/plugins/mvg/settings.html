📍 Wie finde ich meine Haltestellen-ID?

Option 1: Hilfsskript verwenden (empfohlen)

  1. Öffne ein Terminal im InkyPi-Verzeichnis
  2. Führe aus: python scripts/find_mvg_station.py
  3. Gib den Namen deiner Haltestelle ein
  4. Kopiere die angezeigte Station-ID

Option 2: Bekannte Station-IDs

  • Hauptbahnhof München: de:09162:6
  • Marienplatz: de:09162:2
  • Sendlinger Tor: de:09162:4

Option 3: MVG Website

  1. Besuche mvg.de
  2. Suche deine Haltestelle
  3. Die ID findet sich im Format: de:09162:NUMMER
